# Session 10: A File-Based To-Do List

Run these commands from this directory:

- `node addTask.js "Buy groceries"` adds a task unless the same task already exists (case-insensitively).
- `node listTasks.js` prints all saved tasks with one-based numbers.
- `node removeTask.js 1` removes the first task and prints the updated list.

Tasks are stored one per line in `todo.txt`.
